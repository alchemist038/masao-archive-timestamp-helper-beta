# Archive Timestamp Helper Beta

まさおの家のYouTubeライブアーカイブを見ながら、現在位置から指定秒数を引いたタイムスタンプと定型文を記録するChrome拡張の試作品です。

## できること

- まさおの家のライブアーカイブページの右下に小さな操作パネルを表示
- 他チャンネル、通常動画、配信中のライブではパネルを非表示
- 初期値では現在位置の3秒前を記録
- `ゴロン`、`あくび`、`ちもしー` の定型文ボタン
- ショートカットで定型文を追加
- 記録した行の時刻ジャンプ、秒単位の時刻調整、メモ編集、削除、直前取り消し
- コメント欄用テキストをクリップボードにコピー
- 設定画面で定型文、キー、秒数補正、出力テンプレートを変更

## ローカル読み込み

1. Chromeなら `chrome://extensions`、Edgeなら `edge://extensions` を開く
2. 右上の「デベロッパー モード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. このフォルダを選ぶ

```text
D:\MD\context\projects\masao\youtube-timestamp-helper-prototype
```

読み込み後、まさおの家のライブアーカイブページを開き直すと右下にパネルが出ます。

設定は、右下パネルの「設定」、またはブラウザ上部の拡張機能アイコンから開けます。

## 初期ショートカット

- `Alt + G`: `ゴロン`
- `Alt + A`: `あくび`
- `Alt + C`: `ちもしー`
- `Alt + T`: タイムスタンプだけ追加
- `Alt + Z`: 直前の追加を取り消し

コメント入力欄や検索欄にフォーカスしている時はショートカットを無視します。

## 時刻の微調整

記録した行の時刻ボタンを押すと、その位置へジャンプします。

時刻の横にある `-` / `+` ボタンで、その行だけ時刻を調整できます。

- 通常クリック: 1秒戻す / 1秒進める
- `Shift` + クリック: 5秒戻す / 5秒進める

## 出力例

```text
0:12 ゴロン
3:48 あくび
12:07 ちもしー
```
