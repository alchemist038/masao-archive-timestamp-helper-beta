# Chrome Web Store Listing Draft

## 表示名

Archive Timestamp Helper Beta

## 短い説明

まさおの家のライブアーカイブ視聴中に、3秒前のタイムスタンプと定型文をすばやく記録できます。

## 詳細説明

Archive Timestamp Helper Betaは、まさおの家のYouTubeライブアーカイブを見ながら、コメント欄用のタイムスタンプ作成を支援する拡張機能です。

対象外のチャンネル、通常動画、配信中のライブでは操作パネルを表示しません。

動画を止めずに、右下の小さなパネルまたはショートカットキーから、現在位置より少し前のタイムスタンプを記録できます。初期設定では3秒前を記録します。

主な機能:

- 現在位置から指定秒数を引いたタイムスタンプを追加
- `ゴロン`、`あくび`、`ちもしー` などの定型文ボタン
- ショートカットキーで定型文を追加
- 記録した行の編集、削除、直前取り消し
- コメント欄へ貼り付けやすい形式でコピー
- 設定画面で定型文、キー、秒数補正、出力テンプレートを変更

このベータ版は、限定公開でのテスト配布を想定しています。コメントの自動投稿は行いません。

## 権限の説明

### `storage`

設定、定型文、動画ごとのタイムスタンプ一覧をユーザーのブラウザ内に保存するために使います。

### `clipboardWrite`

作成したタイムスタンプ一覧を、ユーザー操作によってクリップボードへコピーするために使います。

### `https://www.youtube.com/*`

まさおの家のライブアーカイブ上に操作パネルを表示し、動画の現在位置、チャンネルID、ライブアーカイブ判定に必要なページ情報を取得するために使います。

## 単一目的の説明

まさおの家のYouTubeライブアーカイブ視聴中に、コメント欄用のタイムスタンプと定型文を記録、編集、コピーできるようにすること。

## データ利用の説明

この拡張機能は、定型文設定、秒数補正、動画ごとのタイムスタンプ一覧をブラウザ内に保存します。外部サーバーへの送信、販売、広告利用、第三者提供は行いません。
