# タイムスタンプ作成を手伝う拡張機能のテスト版を用意しました

まさおの家のライブアーカイブで、視聴者さんがタイムスタンプを作りやすくするためのChrome/Edge向け拡張機能を試作しました。

まだ正式公開前のテスト版です。使ってみたい方は、下の説明を読んだうえで手動インストールをお願いします。

※この下にZIPファイルのダウンロードリンクを入れる予定です。  
※画像付きのインストール説明PDFも用意しています。

## これは何？

ライブアーカイブを見ながら、コメント欄に貼るタイムスタンプを作るための補助ツールです。

動画を止めなくても、ボタンやショートカットキーで「3秒前の時刻」と定型文を記録できます。

たとえば、こんな形でコピーできます。

```text
0:12 ゴロン
3:48 あくび
12:07 ちもしー
```

コメント欄への自動投稿はしません。最後は自分で確認して、コピーしたものをコメント欄に貼る形です。

## できること

- 現在位置の3秒前のタイムスタンプを記録
- 「ゴロン」「あくび」「ちもしー」などの定型文ボタン
- ショートカットキーで記録
- 記録した行の編集、削除、直前取り消し
- コメント欄に貼りやすい形でコピー

## 表示される場所

この拡張機能は、まさおの家のライブアーカイブだけで表示されるようにしています。

他のチャンネル、通常動画、配信中のライブでは表示されません。

## インストール方法

1. ZIPファイルをダウンロードします
2. ZIPを右クリックして「すべて展開」します
3. Chromeなら `chrome://extensions` を開きます
4. Edgeなら `edge://extensions` を開きます
5. デベロッパーモード、または開発者モードをオンにします
6. 「パッケージ化されていない拡張機能を読み込む」または「展開して読み込み」を押します
7. ZIPを展開したフォルダを選びます

ZIPのままでは読み込めません。必ず展開してから、`manifest.json` が入っているフォルダを選んでください。

詳しい手順は、画像付きPDFを見てもらうのが一番わかりやすいと思います。

## ショートカット

- `Alt + G`: ゴロン
- `Alt + A`: あくび
- `Alt + C`: ちもしー
- `Alt + T`: 時刻だけ追加
- `Alt + Z`: 直前の追加を取り消し

コメント入力欄や検索欄にカーソルがある時は、ショートカットは反応しないようにしています。

## 注意

これはテスト版です。

手動インストール版なので、ブラウザ側から警告や確認表示が出ることがあります。自分で入れたものだと分かる場合だけ有効にしてください。

記録した内容や設定は、自分のブラウザ内に保存されます。外部サーバーに送る仕組みは入れていません。
